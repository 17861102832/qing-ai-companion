## ✨ 这是什么

「小青」是一个自研的 **本地 AI 数字人伴侣**，让大模型不再只是一个文本框，而是一个 **看得见、听得懂、记得住你** 的虚拟人。它站在屏幕里，能陪你聊天、听你说话、开口回应、看懂你发的图片，并且 **把你的话真正记住**，下次见面还能接上。

核心定位：**把 AGI 从"文本框"变成一个"有记忆、有人格、可陪伴"的实体。**

---

## 🧠 核心亮点

### 1. 四层记忆中枢（自研）
不是简单的上下文缓存，而是一套分层的长期记忆：
- **道**：你的长期偏好与价值观
- **法**：陪伴与回应的策略
- **术**：具体技能与事实
- **经历**：对话轨迹

它会真正沉淀、归纳你的喜好，让"越聊越懂你"从口号变成事实。

### 2. 一键人格蒸馏
喂一段关于你的描述，即可自动生成一份**专属人格**（核心价值观、口头禅、兴趣），实时刷新系统 Prompt。人格不是模板，是长出来的。

### 3. MBTI 反差人格预设
内置一组有反差的人格（INTJ 冷面军师 / ENFP 快乐小狗 / ISTP 高冷动手派 / ESFJ 暖心大管家），一键切换即可改变人设。

### 4. 全模态交互
- **文字聊天**
- **语音识别**（听你说）
- **语音合成**（它开口说话）
- **视觉理解**（把图丢给它，它能看懂）

### 5. 自定义大模型接入
支持 DeepSeek V4 全系，也支持任意多模态 / 兼容协议模型，密钥在面板一键配置、即时生效、无需重启。

### 6. 音色自由
内置多款女声音色，可一键切换；也支持上传音频做音色克隆。

### 7. Live2D 会动的数字人
角色站在地面，会根据你的话做出小幅互动动作，自然生动。

### 8. 一键安装包
**对方电脑什么都不用装**——双击 `Setup.exe` 走一个安装向导，装完自动启动并弹出界面。所有数据保存在本地，**不上传**，隐私安全。

## 🚀 快速开始

**方式 A：一键安装包（推荐给普通用户）**
1. 解压 `小青_安装包.zip`
2. 双击 `Setup.exe` → 弹出「小青 · 安装向导」→ 点「开始安装」
3. 装完自动启动并打开 `http://localhost:12393/`

**方式 B：源码运行（开发者）**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run_qing.py
```
首次使用：左下角「🧬 小青控制台」→「① 接入 API」粘贴你的 DeepSeek Key。

## 🗺️ 升级路线图

基于社区前沿方案的持续演进方向：

- **音色真实度**：接入 GPT-SoVITS（5 秒零样本即可克隆中文音色），替换默认 TTS

- **实时会话与打断**：参考 OpenTalking，强化实时性与会话记忆
- **形象扩展**：音频驱动人像视频（Wan2.2-S2V / LongCat-Video-Avatar），突破 Live2D 的限制
